5. Exercise 2 – Variables and Data Types
Variables Used
Variable	Data Type	Value	Reason for Selection
speed	int	60	Speed is represented using a whole number
time	float	2.5	Time contains decimal values
distance	double	150.0	Distance may contain decimal values
unit	char	K	Represents a single character

Source Code
#include <stdio.h>

int main(void)
{
    int speed = 60;
    float time = 2.5f;
    double distance = 150.0;
    char unit = 'K';

    printf("Speed: %d\n", speed);
    printf("Time: %.1f\n", time);
    printf("Distance: %.1lf\n", distance);
    printf("Unit: %c\n", unit);

    return 0;
}
Discussion
The int data type was selected for speed because speed is represented using whole numbers. The float data type was selected for time because time may contain decimal values. The double data type was selected for distance because calculated values may require greater precision. The char data type was selected for unit because it stores a single character.
Program Output

Time: 2.5
Distance: 150.0
Unit: K

7. Testing and Troubleshooting

A semicolon was intentionally removed from a statement. The compiler produced an error because every C statement must end with a semicolon. After restoring the semicolon, the program compiled successfully.
Test 2 – Missing New Line Character
The newline character (\n) was removed temporarily. This caused the output to appear on one line instead of separate lines. Reintroducing the newline character corrected the formatting.
Test 3 – Modified Input Values
The speed value was changed from 60 to 100. The result changed from 150.0 to 250.0, confirming that the calculation logic worked correctly.
